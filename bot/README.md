# Telegram‑бот для юристов


## Описание
Telegram‑бот предназначен для юристов и сотрудников компаний, работающих с юридической документацией. Он использует технологию RAG (Retrieval‑Augmented Generation) для:

- быстрого поиска релевантных документов в корпоративной базе знаний;

- анализа законов, договоров и прецедентов;

- формирования обоснованных ответов на запросы.

## Начало работы
1. Отправьте `/start`.

2. Основные кнопки:
   - Отправка RAG-запроса: выберите коллекцию, на основании документов из которой будет осуществляться поиск информации для формирования ответа, после чего введите запрос
   - Поиск по документам: введите запрос, на который система выдаст релевантные документы, в которых может содержаться ответ на него; предварительно выберите коллекцию для поиска и количество документов, которое хотели бы получить в ответ
   - Оплата подписки: первые несколько запросов предоставляются бесплатно, после чего необходимо будет произвести оплату для получения доступа к неограниченному числу запросов;
   - Коллекции. Здесь вы сможете совершать различные действия с коллекциями и документами: создание, изменение (установка другого названия и описания) и удаление коллекций; просмотр документов в коллекциях; добавление, изменение (названия и описания) и удаление документов.

## Как пользоваться
### 1. Отправить RAG‑запрос
1. Нажмите «Отправить RAG‑запрос».
2. Выберите коллекцию.
3. Введите запрос.

### 2. Поиск по документам
Используйте этот режим, чтобы получить **список документов**, соответствующих вашему запросу.

- Нажмите кнопку «Поиск по документам».

- Выберите коллекцию, в которой следует искать документы.

- Укажите количество документов, которое хотите получить

### 3. Оплатить подписку

Первые 10 запросов предоставляются бесплатно. Далее необходимо оплатить подписку для дальнейшего использования.

### 4. Коллекции

#### 4.1 Добавление коллекции

- Вы можете добавить коллекцию, выбрав для неё название и описание, а также определив публичность: будет ли она доступна только Вам или всем пользователям. Данное действие доступно только администраторам.

#### 4.2 Изменение коллекции
- Для каждой существующей, доступной Вам коллекции Вы можете установить новое название и описание. Данное действие доступно только администраторам.

#### 4.3 Удаление коллекции

- Вы можете удалить коллекцию. Данное действие доступно только администраторам.

#### 4.4 Просмотр документов

- Вы можете посмотреть информацию о документах, которые лежат в коллекции: название, описание и ссылку на источник.

### 5. Документы

#### 5.1 Добавление документа

- Вы можете загрузить документ, выбрав для него название, описание и ссылку на источник. Данное действие доступно только администраторам.

#### 4.2 Изменение документа
- Для каждого существующего, доступного Вам документа Вы можете установить новое название и описание. Данное действие доступно только администраторам.

#### 4.3 Удаление коллекции

- Вы можете удалить документ. Данное действие доступно только администраторам.

## Ограничения
- Бесплатные запросы: 10
- Формат документов: `.txt`
